## What this game is, in one paragraph

A 6×5 cluster-pays cascading slot in which every winning cascade moves an expedition one step along a visible track of five stations. Each station changes the grid or the multiplier; the fifth opens a Temple Bonus where the player really chooses one of three chambers whose prizes were fixed before the choice. Free spins keep the multiplier's sun bonus and start each spin from a Base Camp that can be pushed forward.
