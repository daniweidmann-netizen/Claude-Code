| Nr. | Prüfen | Ergebnis |

## E. Technik

| Nr. | Prüfen | Ergebnis |
|---|---|---|
| E1 | Gerät drehen (quer und zurück): Layout stellt sich sauber um, auch mitten in einer Runde | |
| E2 | In Safari scrollen/Adressleiste ein- und ausblenden: Bild springt nicht, nichts verschiebt sich dauerhaft | |
| E3 | Ton: nach dem ersten Antippen hörbar; Stummschalter wirkt sofort; Stummschalter des Telefons wird respektiert | |
| E4 | Zweimal AUTO, dann **i → Performance**: Urteil, Bilder pro Sekunde, Anteil langsamer Bilder, längstes Einzelbild, Effekte (full/light/off) notieren | |
| E5 | Nach etwa 10 Minuten Spielen: Gerät wird nicht auffällig warm, Bildrate bleibt stabil | |
| E6 | App in den Hintergrund und zurück: Spiel läuft weiter, kein Tonfehler | |
| E7 | **i → Rules** ganz unten «Auf Deutsch wechseln»: Oberfläche wechselt die Sprache | |
